# SOF — Centro Operacional

Catálogo de projetos, sandbox de nodes, calendário, chats, filas, Inbox, clientes e conexões Plugins/MCP.

## Executar localmente

Extraia ou clone o projeto e abra `Iniciar-SOF.cmd` no Windows. Com Node.js instalado, também pode executar:

```sh
npm start
```

Acesse http://127.0.0.1:4173/ e mantenha o terminal aberto. Não precisa instalar pacotes ou fazer build.

## Verificar

```sh
npm test
```

Consulte `README-LOCAL.md` para backups e limitações. Os dados de uso ficam no navegador; filas e chats ainda não executam IAs automaticamente. Firebase e deploy automático ainda não estão configurados.
